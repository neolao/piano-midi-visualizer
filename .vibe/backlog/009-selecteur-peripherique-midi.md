# Choisir le périphérique MIDI

## Description
Quand plusieurs claviers sont branchés, l'utilisateur choisit l'entrée à écouter.

## Acceptance Criteria
- [ ] La liste déroulante affiche les entrées MIDI disponibles
- [ ] Choisir une entrée n'écoute plus que celle-ci
- [ ] Si l'entrée choisie est débranchée, le système le signale
