# Afficher un clavier visuel

## Description
Un piano à l'écran s'allume pour les touches actuellement tenues.

## Acceptance Criteria
- [ ] Les touches tenues sont mises en évidence sur le clavier
- [ ] Relâcher une touche la remet à l'état normal
- [ ] Le clavier couvre au moins 88 touches (La0 à Do8)
