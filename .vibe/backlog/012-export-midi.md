# Enregistrer et exporter en fichier MIDI

## Description
Enregistrer une session de jeu et la télécharger au format .mid.

## Acceptance Criteria
- [ ] L'utilisateur peut démarrer et arrêter un enregistrement
- [ ] Le fichier .mid téléchargé se rouvre dans un lecteur MIDI avec les mêmes notes
- [ ] Un enregistrement vide ne propose pas de téléchargement

## Notes
Priorité : NICE. Les durées se calculent à partir des horodatages des messages.
