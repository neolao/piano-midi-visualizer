## Observed patterns
- Les tests Vitest vivent à côté du module testé (`*.test.ts`) ; le dessin VexFlow n'est pas testé dans jsdom.
- La logique (décodage, accords, placement, description, réglages) est pure et sans DOM ; seuls `app`, `midi-panel` et `score` touchent la page.
- Le navigateur est injecté (`MidiEnvironment`, `Storage`, horloge) pour tester sans matériel.
- Le DOM est construit avec `textContent` uniquement, jamais de HTML brut ; les textes sont dans `src/strings.ts`.
- Les styles passent par des variables CSS (`src/styles/tokens.css`), jamais de valeur de couleur en dur.
