# Module: timeline
**Role:** Dessine la partition qui défile pendant que le métronome tourne : curseur fixe, barres de mesure, repères de temps, notes placées selon le moment où elles ont été jouées. Dessinée une fois, puis le calque est déplacé ; mouvement réduit : saut de temps en temps.
**Files:** `src/timeline.ts`
**Exports:** `createTimeline(host, deps?)`, `BEAT_PX`, type `Timeline`
**Depends on:** `modules/grid.md`, `modules/score.md`, `modules/rhythm.md`, `modules/chords.md`
