## Project overview

Page web statique, hébergée sur GitHub Pages, qui capture en direct les notes MIDI d'un piano branché (Web MIDI API) et les affiche sur une partition (VexFlow). Aucun backend : tout s'exécute dans le navigateur.

**Stack:** TypeScript / Vite / Vitest / Biome / VexFlow
**Type:** frontend (site statique)

## Project language

Français — all documentation, backlog items, code comments, and other generated content for this project are written in français.

## Architecture

```
index.html        # point d'entrée Vite
src/
  main.ts         # amorçage de l'application
  midi.ts         # utilitaires MIDI (numéro de note → nom)
  *.test.ts       # tests Vitest, à côté du module testé
vite.config.ts    # base relative (compatible GitHub Pages), env de test jsdom
biome.json        # lint + format
```
